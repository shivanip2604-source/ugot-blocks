Design Brief

Context that frames the whole Criterion B response for this lesson.

Problem context (real world & UAE link): After a building collapse or storm-debris incident, light rubble must be moved by hand-sized tools. A gripper arm with a distance sensor lets a small robot reach, measure and lift without putting a person at risk. In the rescue test the robot also lifts a light model casualty (a 60 g figure, inside the 20–150 g range of B1 7.1) and carries it to a safe zone.

Design task: Design a Python-controlled solution on the ready UGOT kit robot that uses the UGOT Gripper / servo arm + Time-of-Flight (TOF) sensor. It must be programmable, testable and demonstrable by a Grade 10 student in this unit. This is a Digital Design unit: there is no 3D printing or laser cutting.

User: a 14–16 year-old MYP student building, coding, testing and demonstrating the robot in class and at the AIA STEM showcase.

B2 · Design Ideas 3 different ideas

Three ideas that differ in mechanism and form, not just looks. Each sketch is an isometric render of the 3D CAD model with the sensor and mount labelled.

Concept 1 — “Talon-Grip”

Parallel jaws, fixed sensor dome

A two-finger parallel jaw on a lead screw with the TOF sensor fixed on top. Fewest moving parts, but the grip is poor on round or irregular rubble.

Envelope 152.5 × 70.0 × 69.0 mm · ≈ 78 g · ≈ AED 27

Concept 2 — “Claw-Reach” SELECTED

Three-finger claw on a telescoping forearm

A humanoid-style three-finger claw closes radially on a telescoping forearm, with the TOF sensor centred in the palm so it always looks where it grips.

Envelope 306.3 × 61.0 × 64.0 mm · ≈ 134 g · ≈ AED 34

Concept 3 — “Scoop-Paddle”

Hinged scoop with periscope sensor

A hinged scoop slides under flat debris and lifts it, while the sensor sits on a tall periscope mast. Good for flat rubble, but bulky.

Envelope 150.5 × 84.0 × 101.0 mm · ≈ 52 g · ≈ AED 23

5. Pseudocode

START
SET GRIP_DISTANCE to 80   (mm)
SET OPEN to 0, CLOSED to 100   (%)
OPEN the claw
SET state to SEARCH
REPEAT forever
    READ d from the TOF sensor
    IF state is SEARCH AND d <= GRIP_DISTANCE THEN
        CLOSE the claw
        SET state to HOLD
    ELSE IF state is HOLD AND button pressed THEN
        OPEN the claw
        SET state to SEARCH
    END IF
END REPEAT

Pseudocode is plain English with the structure of the code. It must match the flowchart step for step.

Build and test the robot

No 3D printing or laser cutting. Use the ready UGOT kit, write the program in Python and test it against your B1 specification.

  1. Check the kit: UGOT robot with gripper arm and TOF module, laptop. Tell your teacher about any missing part now.
  2. Confirm your B3 design: the kit parts stand in for the “Claw-Reach” sketch (three-finger claw on a telescoping forearm). The part you design is the program.
  3. Assemble with the kit's own instructions, then photograph the finished robot.
  4. Connect the laptop to the UGOT and run a short program: open and close the gripper.
  5. Function-test against the B1 function criteria: Grips and lifts objects of 20–150 g at up to 300 mm reach. Record results in your portfolio.
  6. Test virtually first in the Virtual UGOT simulator: run your Python on a virtual UGOT with the same gripper arm and TOF sensor, rescue the model casualty and copy the test evidence.
  7. Carry on to Criterion C to plan, code, log and justify your changes.
