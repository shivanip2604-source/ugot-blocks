Version 2 of the code and what each line does

02_v2.py · written in Lesson 5 EXEMPLAR
STOP_CM, MAX_TILT = 15, 30

def read_distance():
    d = median([tof_distance_cm() for _ in range(5)])
    return 4 if d == 0 else d      # 0 = inside the 4 cm blind spot

drive_forward(30)
while read_distance() > STOP_CM:
    sleep(0.05)
stop()
flipper_raise(60)
drive_forward(15)
start = time()
while time() - start < 4:
    if gyro_pitch() > MAX_TILT:
        stop(); flipper_raise(0); break
stop()
LineWhat it does and why
STOP_CM = 15The stop distance as a named number, so you change it in one place.
tof_distance_cm()Reads the distance to the obstacle. The TOF module reads 4–200 cm: it returns 0 under 4 cm and 200 above 200 cm.
median([ … for _ in range(5)])Takes 5 readings and keeps the middle one, so a single bad reading cannot trigger a stop.
return 4 if d == 0 else dTreats the blind-spot value 0 as "very close", not "far away".
gyro_pitch() > MAX_TILTChecks the tilt while climbing, and puts the flipper back if it is too steep.
time() - start < 4A time limit, so the robot never keeps driving if something goes wrong.
Placeholder names. The function names in the exemplar follow the uCode block names from the UGOT lessons. Look up the real Python names in your UGOT editor and replace them. Sensor facts to check: TOF range 4–200 cm (0 under 4 cm, 200 above 200 cm).
