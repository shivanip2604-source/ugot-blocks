Read this first. This is a Digital Design unit. You do not 3D print or laser cut: the UGOT robot is provided, so your work is assembling the kit parts, coding in Python and testing the robot. The code, tables and results below are exemplars that show what good evidence looks like EXEMPLAR. How Criterion C connects to Criterion B

B gave you a digital design. C proves you can make a working robot that does the same job, then explains what changed.

From B1 Specification

The criteria a robot can show become your tests: 7.1 Pan covers 180° and tilt covers 60° in under 3 seconds; 7.2 Camera view is never blocked across the full pan and tilt range; face recognised in AI vision mode.

From B3 Chosen design

“Gimbal-Eye” (pan-tilt eyeball) is the sketch you compare with in C4.

From B4 Detailed plans

Code from your system diagram, flowchart, wireframe and pseudocode. Changes to these are explained in C4.

Version 2 of the code and what each line does

06_v2.py · written in Lesson 5 EXEMPLAR
ANGLES = [-90, -45, 0, 45, 90]
switch_to_face_recognition()
found = False
while not found:
    for a in ANGLES:
        pan_to(a)
        sleep(0.6)               # let the camera settle
        if face_recognised("Amira"):
            light_on("green"); play_tone_until_end("C")
            found = True
            break
light_off()
LineWhat it does and why
switch_to_face_recognition()Chooses the AI vision mode. It must be set before the recognition block can work.
face_recognised("Amira")Returns True (1) if the registered face is seen, otherwise False (0).
ANGLES = [-90 … 90]The list of pan positions to scan, from left to right.
sleep(0.6)Waits for the camera to stop moving. A blurry image gave missed faces in version 1.
play_tone_until_end("C")Plays the tone and waits until it ends, so tones do not overlap.
found = True / breakA flag and break stop the scan once the face is found.
Placeholder names. The function names in the exemplar follow the uCode block names from the UGOT lessons. Look up the real Python names in your UGOT editor and replace them. Sensor facts to check: TOF range 4–200 cm (0 under 4 cm, 200 above 200 cm).

Changes to the code (version 1 against version 2) EXEMPLAR

#ChangeEvidenceReason (full justification)
1Fixed view → scan 5 anglesPhoto: the face was outside the frame in version 1The robot cannot see people who are not in front, so it must look around.
2Wait 0.6 s after each moveBlurry frames missed faces in 3 of 10 checksThe camera needs time to settle after the servos move.
