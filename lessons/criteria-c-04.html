How Criterion C connects to A and B

B gave you a digital design. C proves you can make a working robot that does the same job, then explains what changed.

From Criterion A

The client's need and your research. In C4 you check the finished robot still serves this client. See Criterion A.

From B1 Specification

The criteria a robot can show: TOF sensor reads 4–200 cm (7.2), sensor view unblocked (7.3), safe gripper with no pinch trap (6.1), and the gripper holding light objects (7.1). They become your tests.

From B3 and B4

B3 is the chosen sketch you compare with in C4: a three-finger claw, with the TOF sensor looking where it grips. B4 gives the plans you code from: the system diagram, flowchart, state diagram, wireframes and pseudocode. Its CAD size and mass (306 × 61 × 64 mm, about 134 g) stay as the digital design figures, because nothing is fabricated here.

What the prototype is in this unit. The kit gripper and TOF sensor stand in for the B3 claw and sensor pod. Your program is the part you design, so your plan, evidence and changes focus on the code and the tests.

Version 1 of the code and what it does

LineWhat it does and why
GRIP_DISTANCE = 80A named number, so you can change it in one place after testing.
OPEN, CLOSED = 0, 100Names for the two gripper positions (%), so the code reads clearly.
state = "SEARCH"Remembers what the robot is doing, so it does not close again and again.
while TrueKeeps checking the sensor for as long as the program runs.
d = tof_read_mm()Reads how far away the object is (the kit TOF sensor reads 4–200 cm, which is 40–2000 mm).
if … d <= GRIP_DISTANCEThe decision: close only when searching and the object is close.
elif … button_pressed()Lets the operator release the object safely.

Helping the client: the robot grips by itself when it reaches the rubble, so the operator steers and does not have to time the grip.

Placeholder names. tof_read_mm(), gripper_set() and button_pressed() stand for the real UGOT Python functions. Look up the real names in your UGOT Python documentation and use them in your own code.

Changes to the design (B3 against the final robot)

#Original (B3 and B4)Final robotReason for change (full justification)
1Three-finger printed claw.The kit's gripper.This is a Digital Design unit, with no fabrication, and the kit robot is provided. The kit gripper does the same job as the B3 claw: it closes around light rubble. The B3 CAD model remains the digital design, and the robot proves that the function works.
2TOF sensor centred in the palm, at the claw.TOF sensor 35 mm behind the fingertips (kit mount position).The kit mount cannot place the sensor in the palm. The sensor still sees the object (T2 passed), but it reports the distance to the object from behind the fingers, so the trigger distance had to be raised from 80 to 95 mm. This keeps B1 7.3 (sensor view unblocked) met.
3Telescoping forearm for 300 mm reach.Fixed arm pose, with the robot driving to the object.Reach is done by driving the robot, not by extending a tube. The grip logic works at under 100 mm, so this does not affect the function.
4B4 wireframes: custom operator screens with a distance gauge, state label and RELEASE button.The kit's own controller or app for drive and arm. Distance and state are printed in the Python output.Building a custom app is outside this unit. Changes to the code (version 1 → version 2)

Compare the final flowchart in C2 with your B4 flowchart (the plan). The differences are listed here: the B4 flowchart used one reading, and a fixed distance of 80 mm, and had no timeout.

#ChangeEvidence (what went wrong)Reason, and the effect on the result
1GRIP_DISTANCE 80 → 95Console from Lesson 4: the claw closed at 77 mm after the block was pushed.The sensor is 35 mm behind the fingertips and the claw takes time to close while the robot is still moving. Triggering earlier lets the fingers close before contact. The foam block improved from 4/5 to 5/5.
2One reading → median of 5The sponge gave readings jumping between 60 and 140 mm, so the grip triggered late or never.A sponge absorbs the sensor's beam, so single readings are noisy. The median of five ignores stray values. The sponge improved from 3/5 to 5/5.
3Closing speed 100% → 40%The paper cup was crushed in 3 of 5 trials.A slower close gives the gripper time to stop on the object. The cup improved from 2/5 to 4/5. This also makes the gripper safer to work near (B1 6.1).
4Added a 20 s timeout and a finally blockIn test T4, the claw stayed closed on an object when the program was stopped.The program always releases at the end, so an object is never left held and nobody has to pull it out of a closed gripper. B1 6.1 (safe handling) needed this.

Why only one change at a time: it is the only way to know which change helped. Record the effect of each.
